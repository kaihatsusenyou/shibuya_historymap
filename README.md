# 東京歴史マップ

東京の区の歴史スポットを、時代ごとに地図上で巡れるWebアプリです。
画面上部で区を切り替えられます（現在は渋谷区・千代田区・港区）。

## 機能

- 区の切り替え（`index.html?ward=chiyoda` のようにURLで直接開くこともできます）
  - 渋谷区：歴史スポット137件、年表164項目
  - 千代田区：歴史スポット69件、年表89項目
  - 港区：歴史スポット55件、年表77項目
- 縄文時代から令和までの歴史スポットを地図に表示（時代ごとに色分け）
- 区内の地域（渋谷区は8地域、千代田区・港区は6地域）で絞り込み、地名の由来も掲載
- 各スポットに詳しい解説・見どころ・参考資料のリンク
- 写真の表示（Wikipedia の記事で使われているウィキメディア・コモンズの画像を、表示時に読み込み。作者・ライセンスへのリンク付き）
- 戦争・事件・事故・災害・社会問題など「負の歴史」も掲載（「!」マーカー。表示の切り替え・負の歴史だけの表示が可能）
- 区ごとの歴史年表。年表の項目を押すと地図上の場所へ移動
- 時代フィルタ・年代スライダー・キーワード検索による絞り込み
- 国土地理院の**昔の航空写真**（1945〜50年／1961〜69年／1974〜78年）を現在の地図に重ねて比較（透明度調整可）
- 近くのマーカーを数字付きの丸にまとめて表示（拡大すると分かれます）
- スマートフォン対応

## 使い方

ビルド不要の静的サイトです。`index.html` をブラウザで開くだけで動きます。

ローカルサーバーで確認する場合:

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で
このブランチのルートを公開元に指定してください。

## スポットの追加・修正

各区のデータは `data/<区>.js`（`data/shibuya.js`、`data/chiyoda.js`、`data/minato.js`）にあります。
`SPOTS` 配列に項目を追加するだけで地図と一覧に反映されます。
年表は `TIMELINE`、地域区分は `DISTRICTS` で定義しています（スポットの `area` の文字列から地域を自動で判定）。
負の歴史として扱うスポットには `dark`（「戦争」「事件」など）を付けます。
事件・事故については、被害者など個人を特定する情報は載せない方針です。
時代区分と色はすべての区で共通で、`data/common.js` の `ERAS` で定義しています。

## 区の追加

1. `data/chiyoda.js` を参考に `data/<区のキー>.js` を作り、
   `window.WARDS.<区のキー> = { label, center, zoom, districts, spots, timeline }` を登録します。
2. `index.html` にそのファイルの `<script>` を追加します。

年代や由来には諸説あるものや伝承に基づくものが含まれます。
公開前に各区や各施設の公式情報で内容を確認してください。

## 写真について

写真は 各区のデータファイルの各スポットの `wiki`（Wikipedia の記事名）をもとに、
Wikipedia の API から記事のサムネイル画像を読み込んで表示します。
ウィキメディア・コモンズの画像（自由なライセンスの画像）だけを使い、
写真の下に作者・ライセンスが確認できるページへのリンクを表示します。
記事や画像が見つからない場合、写真は表示されません。

## ファイル構成

```
index.html      画面
css/style.css   スタイル
js/app.js       地図・絞り込みの処理
data/common.js  すべての区で共通の設定（時代区分と色）
data/shibuya.js 渋谷区のデータ
data/chiyoda.js 千代田区のデータ
data/minato.js  港区のデータ
```
