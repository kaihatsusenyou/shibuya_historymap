# 渋谷歴史マップ

渋谷区の歴史スポットを、時代ごとに地図上で巡れるWebアプリです。

## 機能

- 縄文時代から令和まで、渋谷区内の歴史スポットを地図に表示（時代ごとに色分け）
- 時代フィルタ・年代スライダー・キーワード検索による絞り込み
- 国土地理院の**昔の航空写真**（1945〜50年／1961〜69年／1974〜78年）を現在の地図に重ねて比較（透明度調整可）
- スマートフォン対応

## 使い方

ビルド不要の静的サイトです。`index.html` をブラウザで開くだけで動きます。

ローカルサーバーで確認する場合:

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で
このブランチのルートを公開元に指定してください。

## スポットの追加・修正

`data/spots.js` の `SPOTS` 配列に項目を追加するだけで地図と一覧に反映されます。
時代区分と色は同じファイルの `ERAS` で定義しています。

年代や由来には諸説あるものや伝承に基づくものが含まれます。
公開前に渋谷区や各施設の公式情報で内容を確認してください。

## ファイル構成

```
index.html      画面
css/style.css   スタイル
js/app.js       地図・絞り込みの処理
data/spots.js   歴史スポットのデータ
```

## 利用データ・ライブラリ

- 地図・航空写真: [国土地理院 地理院タイル](https://maps.gsi.go.jp/development/ichiran.html)
- 地図: © OpenStreetMap contributors
- 地図ライブラリ: [Leaflet](https://leafletjs.com/)
